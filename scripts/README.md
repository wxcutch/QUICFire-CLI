# Overview of Scripts

**NOTE**: These are intended to be run from this directory with the results going to the saveLocation specified by your namelist. Copying these into your project directory is strongly discouraged.

## qf_simulation_setup.py
This will auto-generate the simulation based on the namelist given after the script call. See instructions on namelist setup and description of premade cases in the samples directory


## check_dependencies.sh
Checks that your python environment has everything you need to run these scripts. Either pass it the name of a conda environment or leave the name out to have it check your current environment. 
**TIP**: If the script is struggling to find a conda environment you want to test, activate the conda environment in your current terminal session then run the script.


## create_fastfuels_figures.py
Creates figures depicting the surface fields generated by FastFuels as part of the setup process. You need to provide the namelist you used before.

## qf_cli.py
This provides a lot of common routines for all of the scripts, and isn't intended to be run as standalone by an end user of this system.
